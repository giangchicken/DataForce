How to label

    

      

        
What a sample is

        
One conversation, and the catalog of tools the assistant was allowed to call in it. The
          label is the calls it should have made at the last turn — nothing earlier, nothing the
          catalog does not offer.


        
What makes a label right

        
Every call the turn needs, with the arguments the conversation actually supports. An
          argument nobody stated is a wrong call, not a good guess.

        
No call is an answer. A turn that needs no tool is labelled with an empty list,
          and that is a finished sample — not a row somebody skipped.


        
What you tick, and when

        
On the data: which of the values found really are personal data. A value you
          untick stays in the text as it arrived, and one the scan missed you can type in yourself
          — every place it occurs is found for you. You never ask for the replacement: every value
          still ticked is replaced as you tick, and the Checks panel says how many.

        
On the label: whether it ships as it is, and what kind of sample it is. The facets
          are the only thing here nothing can compute, and nothing can fill one in later — a sample
          stored without one is stored without it for good.

        


        
What gets a sample refused

        
Three things, and only three: nobody ran the personal-data scan; a value the redaction
          confirmed is still in what ships; a facet above that nobody ticked. Each names itself on
          the panel it belongs to, nothing is written, and you stay on the sample.

      

      

    

  






  

    
Import raw data

    


      
One JSON object per line — a .jsonl file. Every line becomes a
        sample waiting to be labelled. Importing the same file twice imports nothing the second
        time, so a failed import is safe to run again.

      
      

        
        
      

      

      
One sample from somewhere else does not need a file: paste it straight into
        the sample pane. That way needs no database at all.
